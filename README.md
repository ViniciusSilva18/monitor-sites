## ✨ Funcionalidades
- ⏱️ Verificação automática a cada 5 minutos
- 📊 Relatório HTML gerado automaticamente
- 📈 Tempo de resposta em ms
- 📋 Log histórico em JSON (últimas 200 verificações)

## 🚀 Setup
```bash
pip install -r requirements.txt
python monitor.py
```
